# Audioguide Schloss Castel Wolfsthurn

## Dateien
- `index.html`: Oberfläche, Sprachwahl, Suche, Stockwerke und Audioplayer
- `stations.js`: Stationstitel, Beschreibungen, Transkripte und Audiodateinamen
- MP3-Dateien: später direkt in das Repository hochladen

## Nummerierung
- 1. Stock: Station 01 bis 13
- 2. Stock: Station 14 bis 17

## Audiodateien
Beispiel Station 1:
- `01-de.mp3`
- `01-it.mp3`
- `01-en.mp3`

Beispiel Station 14:
- `14-de.mp3`
- `14-it.mp3`
- `14-en.mp3`

Solange eine MP3-Datei noch nicht hochgeladen ist, wird der Audioplayer der betreffenden Sprache ausgeblendet.

## Texte bearbeiten
Texte und Übersetzungen werden in `stations.js` ergänzt. Wenn Italienisch oder Englisch noch leer ist, zeigt die Seite vorläufig den deutschen Titel an.
