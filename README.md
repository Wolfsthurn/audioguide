# Audioguide Starter

1. Laden Sie alle Dateien in Ihr GitHub-Repository hoch.
2. Aktivieren Sie unter Settings > Pages: Deploy from a branch, main, /(root).
3. Ersetzen Sie Inhalte in `stations.js`.
4. Legen Sie MP3-Dateien in die Ordner `audio/de`, `audio/it`, `audio/en`.

Wichtig: Die mitgelieferten MP3-Dateien sind nur leere Platzhalter und sollten ersetzt werden.
